# 🎙️ Biz Voice AI

Biz Voice AI is an AI-powered voice assistant designed to help businesses handle routine customer questions quickly and naturally.

Customers can ask questions about business hours, services, appointments, and pricing. The AI uses the provided business information to generate helpful responses.

## ✨ Features

- 🤖 AI-powered customer support
- 🎤 Voice input using speech recognition
- 🔊 AI responses can be spoken aloud
- 💬 Text-based questions and answers
- 🏢 Business-specific information
- ⚡ Fast API-based communication
- 🌐 Frontend and backend architecture

## 🛠️ Technologies Used

### Backend
- Python
- FastAPI
- OpenAI API
- Pydantic
- Python-dotenv

### Frontend
- HTML
- CSS
- JavaScript
- Web Speech API
